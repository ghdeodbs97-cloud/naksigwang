# 어신 벤치마킹 방향

확인일: 2026-11-01. 공개 소개와 스토어 안내를 기준으로 한 기능 비교이며,
어신 앱 내부 구현·정확도·실제 화면 동작을 검증한 결과는 아니다.

참고: [운영사 공식 소개](https://sgma.io/service/eosin-app),
[Google Play 등록 정보](https://play.google.com/store/apps/details?id=io.sgma.uhshin&hl=ko).

## 낚시광에 적용할 흐름

| 사용자가 판단할 것 | 참고할 방향 | 낚시광의 현재 연결점 |
|---|---|---|
| 어디로 갈까 | 포인트를 중심으로 조건을 확인 | 항·갯바위 검색, 지도 선택 |
| 언제 갈까 | 날씨·물때·수온을 시간대별로 확인 | 오늘·물때 탭과 시간 선택 |
| 무엇을 노릴까 | 어종별 조건을 비교 | 입질 탭, 어종 카드, 추천 시간 |
| 현장은 어떨까 | 바람·조류·수심을 지도로 확인 | NAVER 지도와 기존 overlay·A/B |
| 무엇을 기록할까 | 조과를 남겨 다음 출조에 참고 | 기기 내 조과 기록 |

첫 APK는 이 기존 흐름이 휴대폰에서 끊기지 않는지 확인하는 단계다.
UI 개선 시 첫 화면에서 장소·선택 시각·핵심 조건이 분명하고,
지도에서 고른 장소가 오늘/입질 정보와 일관되게 연결되는지를 우선 확인한다.
분석 점수는 검증된 실제 포획 확률과 같다고 표현하지 않으며, 자료 시각·출처·추정 여부를 유지한다.

## 후속 범위

어신에서 안내하는 예약·커뮤니티·커머스는 별도 기능이다. 첫 APK에 구현된 것으로 표시하지 않는다.
로그인·기기 간 동기화·사진 조과·알림·즐겨찾기 등은 실제 사용 확인 뒤 별도 기능 작업으로 결정한다.
낚시광 고유의 데이터·지도 분석을 유지하면서 정보 순서와 터치 흐름을 참고한다.
