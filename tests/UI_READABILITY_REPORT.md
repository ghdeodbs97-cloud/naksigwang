입질의 높음60점 이상/보통40–59점/낮음/없음 범례를 DOM에서 제거했다. 카드의 등급 배지는 유지한다. PC 카드 최소 폭을150→190px로 늘려 1280px 화면에서6열→5열로 정리하고 모바일2열은 유지한다. 본문·보조문구 크기와 행간/여백을 늘렸다. 날짜 버튼과 입력칸의 터치 영역을 정리했다. 기록 입력은 PC4열/모바일2열이며 메모 필드는 한 줄이다.

오래된 자료/오류 경고·추정 표시·공식 자료 링크·라이선스·AI 보완 이미지 안내는 제거하지 않았다. 접는 부분은 기본 details/summary로 키보드와 터치 모두 사용할 수 있다. 공유 지도 stage/단면 패널, 기존 DOM id, 이벤트 연결은 유지한다.
