# 오늘 화면 시간 선택 검증

오늘 그래프를 누르거나 끌어 00:00~23:59를 선택한다. 그래프 아래 슬라이더는 분 단위이며 키보드 Home/End/방향키를 지원한다. ‘지금으로’는 현재 시각 추종을 복원한다. 선택 시각은 오늘 날짜의 지도·물때·입질 화면과 공유한다.

## 표시 기준

- 들물/날물, 바닷물 높이, 다음 만조/간조까지 남은 시간: 선택 시각의 조석.
- 바람·파고: 선택 시각에 대응하는 기존 예보. 자료가 없으면 없음으로 표시한다.
- 조류: 선택 시각의 조류 예보. 예보 지점이 없으면 기존 바닷물 높이 기반 추정임을 표시한다.
- 물때 이름/세기와 일출/일몰: 해당 날짜의 값.
- 수온: 시간별 예보 자료가 없으므로 최근 유효 관측값을 유지하고 관측 날짜·시각을 표시한다. 임의 시간별 수온을 만들지 않는다.

## 자동·화면 확인

`tests/test_today_time.py`는 운영 자료의 생성 시각에서 12시간 뒤로 브라우저 시계를 고정하고 390×844, 1280×900에서 다음을 검사한다.

- 주문진항·격포항의 00:00/06:00/12:00/18:00/23:59 수치가 기존 조석·기상·조류 자료 조회 결과와 일치.
- 별도 메모리 예보를 주입해 시각별 바람·파고 변화와 수온 관측값 유지 확인. 운영 자료 파일은 수정하지 않음.
- 마우스 드래그, 실제 터치 이벤트, 슬라이더 키보드 조작과 양 끝 시각.
- 1분 경과 후 수동 시각 유지, 지금 복귀 후 시계 추종, 미래 날짜 탭에서 오늘 복귀.
- 연속 21회 시간 선택 중 어종 점수 계산 및 하루 추천 재계산 모두 0회.
- 다섯 탭 전환, 브라우저 오류 없음, 모바일/PC 가로 넘침 없음. 두 크기의 화면 캡처를 직접 확인.

빌드, 기본 smoke, 자료 실패 smoke, 입질 신뢰도, 어종 사진, 단면 상태, 빌드 일치 회귀도 함께 확인한다. 지도 제공자 회귀는 별도 20개 화면/DPR 조합 및 실패 상황·수심/단면 기준값 검사를 사용한다.
