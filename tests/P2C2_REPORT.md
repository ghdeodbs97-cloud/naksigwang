# P2C-2 검증된 KHOA 150 m 연안 coverage 확대

최신 main `f8533cb`에서 분기. 실제 수집 2026-10-11. **동해 전체 수심 완성이 아니다.** 원본 측심점이 아닌 공식 해양수치모델용 150 m 격자이며 수직 정확도/조사연도는 미확인이다. 기준면 원문 `평균해면하`를 유지했다.

## 수집/발행

15권역·24부모 연안 bbox에서 기존 범위를 차감해 34개 요청 bbox를 계획했다. [호출 전 계획](P2C2_PLAN.md), [좌표 그림](p2c2_coverage_plan.svg), [전체 요청별 실측 기록](p2c2_collection_audit.json). 계획의 34,332점/135회는 추정이며 실제 결과와 구분한다.

실제 API **129회**, 재시도 0회. 성공 27 bbox/97페이지/24,291개 레코드. 중복 11개 제거 후 **24,280점 추가**, 기존 **11,702점 → 35,982점**. 실패 7 bbox도 원본 응답을 보존했다. 3개 음수 포함 bbox는 모든 28페이지를 받았지만 발행하지 않았다. NODATA_ERROR 4개는 정상 0건으로 바꾸지 않았다. 최종 재개는 **실제 호출 0회**.

기존 10타일의 SHA256/bytes를 모두 보존하고 새 32타일만 추가했다. 42타일 + manifest 1개 = 43파일, **1,414,511 bytes** (기존 455,007 bytes 대비 +959,504). 가장 큰 새 타일 116140 bytes. 점 좌표/수심 정밀도를 줄이거나 용량을 위해 점을 삭제하지 않았다. 원본 API 응답과 환경변수 키는 Git 제외.

KHOA 결과의 출처는 국립해양조사원 자연과학용 수심정보, 기준면 평균해면하, 신뢰도 최대 중간이다. JSON의 `nearestGridComparison`은 각 대표점 최근접 **원 격자 좌표에서** KHOA 원값과 기존 fallback을 비교하며 좌표 차이 0 m다. 기존 fallback 기준면은 모델 `unknown` 또는 GEBCO `MSL_assumed`이므로 수치 차이는 수직 정확도 평가가 아니다.

해안 바로 옆은 유효 후보로 둘러싸이지 않아 fallback이 자주 선택된다. 격자 보간 범위를 억지로 넓히지 않았다. 225 m 반경, 같은 자료집/기준면, 육지 통과 차단과 유효 점 볼록껍질 내부 조건을 유지한다. 새 `coverageBoxes`로 부모 bbox 안 미수집 구멍도 제외했다. 실제 해안선의 정밀도와 작은 누락은 별도 검증이 필요하다.

## 테스트/변경

[전체 로컬 CI 결과](p2c2_ci_results.json). workflow의 모든 검사 명령 통과: Python 문법, collector 22, boot degradation, build missing ids: [], smoke, degraded smoke, P1, GIS converter 7, P2B foundation, KHOA fetch 18, KHOA depth, 신규 cache/resume/publish 12, 신규 다중 지역 browser. API 키를 제거한 검사 환경, 합성 fixture/메모리 route만 사용하며 실 API 호출은 CI에 요구하지 않는다. 최종 발행기 수정 뒤 해당 12개 회귀도 재실행 통과. 390×844/1280×900 다섯 탭·위치조회·단면 캡처를 직접 검수했다.

변경: 연안 계획/수집 캐시/발행/검증 CLI 4개, 32개 새 타일 및 manifest, 04b 로더의 실제 bbox 묶음/진행 중 요청 공유, 04_depth 상세의 자료점 거리, 기존 출처 문구/README/생성 index, mock 검사 2개와 CI, 계획·실측·성능·비교 보고서. 새 설정/위성지도/수심 모델은 추가하지 않았다.

미확인: 음수 dpwt의 공식 의미, NODATA 원인, 수직 정확도·조사연도·실기기 메모리. 미탑재 7개 bbox와 보수적인 해안 경계 fallback을 명시한 부분 coverage 확대다. main 직접 수정/merge 없이 전용 브랜치에서 PR로 검토한다.
